Ao continuar, você solicita o acesso deste dispositivo ao SLMsys. Para análise e segurança, serão registrados o horário da solicitação, navegador/dispositivo, idioma, fuso horário e localização aproximada informada pelo navegador.

✨ Animações do Sistema

O sistema usa animações suaves nos botões, cards, telas e janelas para ficar mais agradável de usar. Todos os interruptores ficam reunidos aqui, em um único grupo — deixe ligado o que gosta e desligue o resto (útil também se o aparelho for mais fraco). Área protegida por senha.

Escolha a aparência dos painéis do sistema: efeito de vidro derretido (translúcido, com desfoque) ou opaco (sólido, sem transparência). Guardado só neste aparelho.

Etiqueta de Produtos

Etiqueta impressa em 50mm x 30mm, com nome, preço, código de barras e QR code do produto. As opções acima valem para todas as etiquetas da loja.

No editor você adiciona os elementos que quiser (nome, preço, código de barras, QR code, logo, retângulo, textos livres...), arrasta cada um para a posição desejada, redimensiona pelo canto e ajusta fonte, tamanho e cor individualmente. Cache Local (dados salvos neste aparelho)

Toda alteração feita aqui é salva automaticamente neste aparelho (fora do servidor), e esses dados NÃO somem ao reiniciar o aparelho ou fechar o app. É esse cache que permite continuar usando o sistema mesmo sem internet — e é ele também que é enviado ao servidor assim que a conexão voltar.

Espaço usado agora: —

Use isto só se o aparelho estiver com pouco espaço ou se algo parecer corrompido. Se limpar enquanto houver alguma alteração que ainda não foi enviada ao servidor (feita sem internet), essa alteração é perdida — o sistema avisa antes de continuar.
