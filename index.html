✨ Aparência

O sistema usa animações suaves nos botões, cards, telas e janelas para ficar mais agradável de usar. Se preferir um visual mais direto e sem movimento (ou se o aparelho for mais fraco), desligue com o botão abaixo.

Etiqueta de Produtos

Etiqueta impressa em 50mm x 30mm, com nome, preço, código de barras e QR code do produto. As opções acima valem para todas as etiquetas da loja.

No editor você adiciona os elementos que quiser (nome, preço, código de barras, QR code, logo, retângulo, textos livres...), arrasta cada um para a posição desejada, redimensiona pelo canto e ajusta fonte, tamanho e cor individualmente. Você pode salvar quantos modelos quiser, cada um com seu próprio nome, e escolher qual usar na hora de imprimir a etiqueta de cada produto.
